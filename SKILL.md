# Управление Jino

Используй CLI и компактный JSON. Он входит по login/password, выполняет прямые HTTP-запросы и принимает любой домен, доступный аккаунту.

## Запуск

```powershell
$jino = Join-Path $env:USERPROFILE '.codex/skills/jino-control/scripts/jino.ps1'
& $jino status
& $jino domains list
& $jino dns list example.com --type A
```

`status` работает без сети. Если `credentials_configured=false`, пользователь один раз запускает `& $jino auth configure` в своём интерактивном терминале. Windows DPAPI хранит пароль зашифрованным для текущего пользователя. Альтернатива — уже настроенные `JINO_LOGIN` и `JINO_PASSWORD`. Пароль вводится пользователем локально; не запрашивай его в чате и не передавай в аргументах команд. `auth check` проверяет реальный вход.

## DNS

По результату `dns list` выбери точный `id`, имя и тип записи. `--name @` означает корень зоны. Для изменения IP:

```powershell
& $jino dns ip example.com --record-id 123 --ip 203.0.113.42
& $jino dns ip example.com --record-id 123 --ip 203.0.113.42 --expected-value 203.0.113.10 --apply
```

Первый вызов показывает план. `--apply` выполняет изменение в пределах запроса пользователя; флаг сам по себе не даёт разрешение на дополнительные действия. Уже данное разрешение не запрашивай повторно. `dns ip` сохраняет имя и тип; `--expected-value` проверяет актуальное значение перед записью, но не обеспечивает атомарность на сервере.

```powershell
& $jino dns add example.com --type A --name api --ip 203.0.113.42 --apply
& $jino dns delete example.com --record-id 123 --apply
```

Для списка обычно достаточно `--type`, `--name`, `--limit 20`; следующая страница — `--offset` из `next_offset`. `--full` нужен только для дополнительных полей. Синтаксис редкой команды получай через её `--help`, не читая весь исходный SDK.

## Результат

Успех изменения подтверждён только при `outcome=applied` и `verification=read_back`. `outcome=planned` означает, что записи не было. При `RESULT_UNVERIFIED`, `WRITE_RESULT_UNKNOWN`, `PARTIAL_UPDATE` или прерывании прочитай актуальное состояние; не повторяй запись автоматически. Сервер может применить запрос до тайм-аута. Несколько настроек выполняются последовательно; проверяй `steps` при частичном результате.

Для настроек, сложных DNS, контактов, SSL, поддоменов и сброса зоны читай [references/advanced.md](references/advanced.md) только по необходимости.

## Границы

Рабочий путь — прямой HTTP CLI. Selenium, Playwright, Puppeteer и другие эмуляторы браузера запрещены, в том числе для исследования трафика. Если понадобится уточнить протокол, используй Network/CDP настоящего встроенного браузера.

CLI не регистрирует и не покупает домены, не выполняет платное продление. HTTP-вход по сохранённым данным и чтение доменов/DNS/настроек/NS/SSL проверены на аккаунте. Мутации и полное совпадение POST входа с браузером пока не подтверждены. При CAPTCHA или изменении протокола сообщи причину остановки; успешное чтение не доказывает работоспособность записи.
